# huawei-auto-pal 使用指南

> 你的个人 AI 工作助手：自动分析你的工作痕迹，发现重复浪费时间的问题，并生成技能帮你以后避免。

## 它能做什么

huawei-auto-pal 会回顾你最近的工作（AI 编码会话、git 提交、浏览器记录、邮件、会议等），找出你反复浪费时间的地方，然后：

1. **诊断** —— 告诉你时间花在了哪里、哪些问题反复出现
2. **生成技能** —— 针对每个反复出现的问题，生成一个可安装的技能，帮你下次遇到同样情况时快速解决
3. **生成记忆** —— 提取你的个人偏好和环境信息，让 AI 更懂你

整个过程**全自动**，不需要你手动记录任何东西。

## 一、安装（5 分钟）

### 1. 确认环境

你只需要 **Python 3.9+**。在终端运行：

```bash
python --version
```

如果显示 `Python 3.9` 或更高，就可以了。

### 2. 获取技能

从 AgentCenter 下载 `huawei-auto-pal-x.x.x.zip`，解压到你的 AI 助手技能目录：

| AI 助手 | 技能目录 |
|---|---|
| Claude Code | `~/.claude/skills/` |
| CodeAgent | `~/.cac/skills/` |
| OpenCode | `~/.config/opencode/skills/` |

解压后目录结构：

```
~/.cac/skills/huawei-auto-pal/
├── SKILL.md              ← 主技能文件
├── retro-scope/          ← 诊断组件
├── skill-forge/          ← 技能生成组件
├── env.example           ← 可选凭据模板
└── README.md             ← 详细文档
```

### 3.（可选）配置数据源

**不配置也能用**——开箱即用的数据源有：AI 编码会话、git、浏览器历史、VS Code 历史、Windows 最近文件。

**想接入 WeLink 会议/邮件/日历和 git 提交历史？** 一条命令自动配置：

```bash
python retro-scope/scripts/run.py --provision --git-email 你的邮箱@huawei.com
```

这会自动安装 welink-cli 并启动登录（扫码即可），同时配置 git 身份。整个过程不到 1 分钟。

其他可选凭据（CodeHub 代码评审 token 等），复制凭据模板并填写：

```bash
cd ~/.cac/skills/huawei-auto-pal
cp env.example .env
# 用文本编辑器打开 .env，填入你的 token
```

详细凭据获取步骤见 `README.md` 的"凭据配置"章节。

## 二、使用（一句话搞定）

在你的 AI 助手里，直接对它说：

> 分析一下我最近的工作

或者：

> 总结一下最近的时间花在哪了

或者：

> 帮我自演进

就这样。AI 会自动启动 huawei-auto-pal，完成全部流程。

## 三、会发生什么（全自动流程）

你不需要做任何选择，AI 会自动按顺序执行：

### 第 1 步：环境检查

AI 检查你的电脑上有哪些数据源可用，告诉你哪些能用、哪些需要额外配置。**不会收集任何个人数据**，只检查工具是否存在。

### 第 2 步：诊断（retro-scope）

AI 分析你最近 90 天的工作痕迹，生成多时段报告（90天/30天/7天/1天），告诉你：

- 哪些任务占用了你最多**人工时间**
- 哪些问题在多个会话中**反复出现**
- 哪些操作有**自动化**的空间

### 第 3 步：生成技能（skill-forge）

针对诊断发现的问题，AI 会：

- 生成新的技能文件，写入 `output/` 目录
- 为每个技能生成一份**中英双语提案**（PROPOSAL.md），解释：
  - 问题是什么
  - 证据是什么（哪些会话、浪费了多少时间）
  - 为什么建议安装这个技能
  - 安装后有什么好处

### 第 4 步：展示提案 + 询问安装

AI 会**用你的语言**（自动检测中文/英文）逐个展示每个技能的提案，然后问你：

> 这些技能你想安装到哪个助手？（CodeAgent？Claude Code？）

你可以说：
- "装到 CodeAgent" —— 安装到你指定的助手
- "都装" —— 安装到所有检测到的助手
- "先不装" —— 跳过安装，继续下一步

**这一步需要你确认**——安装技能到你的助手是 Tier 3 操作（最高安全级别），必须你本人同意。

### 第 5 步：自动归档

AI 自动把 `output/` 目录打包到你的 Downloads 文件夹：

```
C:\Users\你的工号\Downloads\huawei-auto-pal-output-你的工号-20260806-143022.zip
```

这是你的个人备份，包含时间分析报告、生成的技能和记忆。**不需要你做任何操作**。

---

## 四、安装生成的技能

当 AI 问你"想安装到哪个助手"时，它会列出检测到的助手。你只需告诉它：

| 你说的话 | 会发生什么 |
|---|---|
| "装到 CodeAgent" | 技能复制到 `~/.cac/skills/` |
| "装到 Claude Code 和 CodeAgent" | 技能复制到两个目录 |
| "都装" | 安装到所有检测到的助手 |
| "先不装" | 跳过，技能留在 output/ 里，以后可以手动装 |

安装后**重启你的 AI 助手**，新技能就会生效。

## 五、常见问题

### Q：会收集我的隐私数据吗？

**不会泄露**。所有分析都在你本地进行，`output/` 目录被 gitignore 排除，不会上传。生成的归档 zip 也在你自己的 Downloads 里。AI 只分析你自己的活动痕迹，不会分析别人的。

### Q：不配置 .env 能用吗？

**能**。开箱即用的数据源包括：Claude Code 会话、CodeAgent 会话、git、Chrome/Edge 历史、VS Code 历史、Windows 最近文件。零配置即可运行第一次分析。

### Q：多久运行一次？

建议每周运行一次。AI 会自动记住上次分析到哪里（独立水印），只分析新增的数据。

### Q：生成的技能是什么格式的？

标准 `SKILL.md` 格式，和你从 AgentCenter 下载的技能一样。每个技能包含：触发条件、操作步骤、非触发条件、权限边界。

### Q：我不想安装某个技能，但想保留它

技能会保留在 `output/` 目录里，并且会包含在每次的归档 zip 中。你随时可以手动复制到助手的技能目录，或者下次运行时再让 AI 安装。

### Q：怎么把 huawei-auto-pal 分享给同事？

在技能目录下运行：

```bash
python skill-forge/scripts/register.py --dist
```

会生成 `huawei-auto-pal-1.0.12.zip`（不含你的个人数据），上传到 AgentCenter 即可。
